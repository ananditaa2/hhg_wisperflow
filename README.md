## 🌟 What is WisprVerse?

Instead of building a simple single-purpose app, our team engineered **WisprVerse**—an integrated 4-in-1 voice-native software suite that demonstrates the sheer breadth and velocity of voice-driven development. 

WisprVerse covers all core technical archetypes in one sleek, obsidian-glassmorphic cockpit:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              ⚡ WISPRVERSE DEVELOPER SUITE                              │
│   [ 🛠️ Dev HUD (Tool) ]  [ 🎮 Sonic Jump (Game) ]  [ ⚡ Automations ]  [ 🧪 Voice Canvas ]│
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. 🛠️ The Developer Cockpit & Telemetry (Tool / Utility)
* **Real-Time Web Audio FFT Spectrum:** Native 48kHz microphone frequency analyzer rendering 60 FPS neon gradient waveforms.
* **Flow Multiplier Engine:** Real-time velocity gauge calculating spoken words per minute (160+ WPM) vs. mechanical typing (45 WPM) — proving a **3.6x–4.0x speedup**.
* **Developer Health Metrics:** Tracks keystrokes spared and repetitive strain injury (RSI) friction eliminated.
* **Spoken Intent Sandbox:** Pre-loaded developer prompts with one-click voice simulation.

### 2. 🎮 Sonic Jump: Bug Buster (The Game)
* **Voice-Controlled Physics:** A canvas arcade game where player jump height and propulsion are controlled directly by vocal volume and pitch!
* **Dodge Real Dev Hazards:** Jump over bugs (`🐛 BUG #404`), syntax errors, and merge conflicts.
* **Celebration Engine:** Confetti particle explosions and dynamic audio synth oscillators on milestone achievements.

### 3. ⚡ Spoken Pipeline Orchestrator (The Automation)
* **Hands-Free Dev Automations:** Trigger complex development and DevOps workflows using natural speech macros:
  * *"Wispr, deploy main branch to staging cluster"*
  * *"Wispr, run comprehensive security audit"*
  * *"Wispr, generate typescript API client from schema"*
  * *"Wispr, spin up local Postgres and Redis cluster"*
* **Real-Time DAG & Terminal:** Visual execution DAG with animated status states and streaming terminal logs.

### 4. 🧪 Voice-to-Architecture Canvas (The Experiment)
* **Neural-Acoustic Topology:** Interactive node-graph mapping the journey of spoken vibrations into executable software code.
* **Live Packet Tracing:** Trace data packets in real-time from *Audio Ingestion* $\rightarrow$ *Wispr Flow Engine* $\rightarrow$ *Intent Extractor* $\rightarrow$ *Agent Synthesizer* $\rightarrow$ *Sandbox*.

## 🚀 Quickstart & Local Setup

### Prerequisites
- Node.js (v18 or higher recommended)
- Modern web browser (Chrome, Edge, Brave, or Safari) with microphone access

### Installation & Run

```bash
# 1. Clone the repository
git clone https://github.com/your-username/wisprverse.git
cd wisprverse

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser. Click **"Start Audio"** in the top bar to enable live microphone reactivity!
